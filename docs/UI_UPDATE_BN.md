# নতুন ড্যাশবোর্ড UI আপডেট

## কী বদলেছে
- লগইন/সাইন আপ পেজ অপরিবর্তিত।
- লগইনের পরের ইন্টারফেস Connectify-স্টাইলে সাজানো হয়েছে: উপরে টপবার, বাঁ পাশে সাইডবার, মাঝখানে কভার ফটোসহ প্রোফাইল, সাপ্তাহিক ইনসাইটস, ছবি/ভিডিও সেকশন, ডান পাশে বন্ধু ও পোস্টের তালিকা।
- সব ফাংশন (যাচাইকরণ, পোস্ট, লাইক, মন্তব্য, গ্রুপ, মেসেজ, অ্যাডমিন) আগের মতোই আছে।

## ইনসাইটসের তথ্য
- এনগেজমেন্ট রেট = তোমার যত শতাংশ পোস্টে অন্তত একটি লাইক/মন্তব্য এসেছে।
- ক্যাম্পাস বন্ধু = একই বিশ্ববিদ্যালয়ের যাচাইকৃত শিক্ষার্থীর সংখ্যা।
- মোট লাইক/মন্তব্য ও সেরা পোস্ট = ডেটাবেজের প্রকৃত তথ্য।

## বাকি আছে
- ছবি/ভিডিও আপলোড, প্রোফাইল ছবি আপলোড, ভিডিও ও সংরক্ষিত পোস্ট বিভাগ এখনো যুক্ত হয়নি (বাটনে ক্লিক করলে বার্তা দেখাবে)।

## আপডেট করার নিয়ম
